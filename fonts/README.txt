FONTS FOLDER  /  پوشه فونت‌ها
================================

EN
--
Put font files (.woff2 .woff .ttf .otf) in this folder to try them on the site.
Nothing here = the built-in fonts are used.

Automatic (by file name):
  display.woff2      -> English headings
  body.woff2         -> English body text
  display-fa.woff2   -> Persian headings
  body-fa.woff2      -> Persian body text
  Several weights of one role: body-400.ttf, body-700.ttf ...

Any other file name: open the site with run.bat, click the round "Aa" button
(bottom-left corner) and choose the font for each role from the list.
The "Aa" button only appears when running locally, never on the published site.
After adding or removing files, refresh the browser.

FA
--
فایل فونت (woff2، woff، ttf یا otf) را داخل همین پوشه بگذارید تا روی سایت تست شود.
اگر این پوشه خالی باشد، همان فونت‌های فعلی سایت استفاده می‌شوند.

انتخاب خودکار با اسم فایل:
  display.woff2      ← تیترهای انگلیسی
  body.woff2         ← متن‌های انگلیسی
  display-fa.woff2   ← تیترهای فارسی
  body-fa.woff2      ← متن‌های فارسی
  چند وزن برای یک نقش: body-fa-400.ttf و body-fa-700.ttf و ...

با هر اسم دیگری: سایت را با run.bat باز کنید، روی دکمه گرد «Aa» گوشه پایین سمت چپ
بزنید و برای هر بخش، فونت دلخواه را از لیست انتخاب کنید.
دکمه «Aa» فقط موقع اجرا روی کامپیوتر خودتان دیده می‌شود، نه روی سایت منتشرشده.
بعد از اضافه یا حذف کردن فایل، صفحه مرورگر را Refresh کنید.
